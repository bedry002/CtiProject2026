Expected format

CycloneDX 1.4+ JSON. Each component should include a CPE identifier and criticality property for best scoring accuracy. Components without criticality get one assigned automatically based on type.

{
  "bomFormat": "CycloneDX",
  "specVersion": "1.6",
  "components": [
    {
      "type": "application",
      "name": "FortiGate Firewall",
      "version": "7.4.3",
      "cpe": "cpe:2.3:o:fortinet:fortios:7.4.3:*:*:*:*:*:*:*",
      "supplier": { "name": "Fortinet" },
      "properties": [
        { "name": "criticality", "value": "high" }
      ]
    }
  ]
}
